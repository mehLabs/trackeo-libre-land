# Política de Privacidad de TrackeoLibre

Última actualización: 9 de junio de 2026

TrackeoLibre es una extensión de Chrome para MercadoLibre Argentina que ayuda a detectar cambios reales de precio en productos visibles dentro del carrito de compras.

## Resumen

TrackeoLibre funciona localmente en el navegador del usuario. La extensión no crea cuentas, no solicita autenticación, no usa servidores propios, no incorpora analítica, no vende datos y no transmite información a terceros.

## Datos que maneja la extensión

Para cumplir su función, TrackeoLibre puede leer información visible en la página del carrito de MercadoLibre Argentina, incluyendo:

- título del producto;
- URL del producto;
- precio actual visible;
- moneda;
- fecha y hora en que se registró un precio;
- preferencias de visualización configuradas desde el popup de la extensión.

Estos datos se usan únicamente para comparar el precio actual de un producto con precios registrados anteriormente y mostrar indicadores de cambio dentro del carrito.

## Almacenamiento local

TrackeoLibre guarda los datos de seguimiento y configuración usando `chrome.storage.local`, el almacenamiento local provisto por Chrome para extensiones.

Esto significa que los datos permanecen en el navegador/dispositivo del usuario. TrackeoLibre no envía estos datos a servidores propios ni a servicios externos.

## Uso de permisos

TrackeoLibre solicita el permiso `storage` para guardar localmente la configuración y los registros de precios.

La extensión también se ejecuta únicamente en páginas del carrito de MercadoLibre Argentina bajo:

`https://www.mercadolibre.com.ar/gz/cart*`

Este acceso se usa solo para leer los productos y precios visibles en el carrito y mostrar la información de seguimiento.

## Compartición de datos

TrackeoLibre no comparte, vende, alquila ni transfiere datos del usuario a terceros.

La extensión no usa servicios de analítica, publicidad, seguimiento externo ni herramientas de medición de comportamiento.

## Transferencia de datos

TrackeoLibre no transmite datos personales, historial de navegación, contenido del carrito ni registros de precios a servidores externos.

Todo el procesamiento necesario para la funcionalidad actual ocurre localmente en el navegador.

## Retención y eliminación de datos

Los registros de precios y preferencias permanecen guardados localmente mientras la extensión esté instalada o hasta que el usuario borre los datos de la extensión desde Chrome.

El usuario puede eliminar estos datos desinstalando la extensión o borrando los datos almacenados por la extensión desde la configuración del navegador.

## Cambios futuros

En el futuro, TrackeoLibre podría incorporar funciones opcionales como autenticación, sincronización entre dispositivos u otros servicios conectados. Si eso ocurre, esta política será actualizada antes de habilitar dichas funciones, explicando qué datos se recopilan, cómo se usan, dónde se almacenan y con quién se comparten.

La versión actual de TrackeoLibre no incluye esas funciones.

## Cumplimiento de uso limitado

TrackeoLibre usa los datos a los que accede únicamente para proporcionar su función principal: registrar y mostrar cambios de precio en productos del carrito de MercadoLibre Argentina.

TrackeoLibre no usa los datos para publicidad, perfilado, venta de información, análisis externo ni fines no relacionados con la funcionalidad principal de la extensión.

## Contacto
